ATS (Address Translation Services) lets a device request and cache translations. Its ATC (Address Translation Cache) retains results, while a TA (Translation Agent) supplies translation and protection information. Mapping changes therefore need invalidation as well as translation lookup.

Place the translation participants before tracing DMA

DMA (Direct Memory Access) can use platform address translation. Figure 10-1 locates the ATC (device translation cache), agent, and protection tables; Figure 10-2 follows requests and completions. The agent checks configuration and access rights. Base 6.0 Chapter 10 does not define every platform page-table format, IOMMU (Input/Output Memory Management Unit) register set, or operating-system interface.

Synchronize a changed mapping

Author scenario: a device may retain an old page translation while the platform changes its mapping. Section 10.3 requires invalidation to maintain consistency. Figures 10-18/10-19 give mode-specific formats; Figure 10-5 illustrates one invalidation with multiple completions. These are invalidation acknowledgements, not application read completions. Memory reuse must respect invalidation, outstanding accesses, and platform lifetime rules.

Identify the address space

PASID (Process Address Space ID) is interpreted with Requester ID; equal PASID values in different functions are unrelated. It travels in a PASID prefix in Non-Flit Mode and OHC-A1 in Flit Mode. PASID Enable is required, and translated requests carrying PASID require the additional enable condition in section 6.20.1.

Connect page requests without merging the protocols

PRI (Page Request Interface) asks the platform to satisfy page needs; it is not an ATS completion. The section 10.4 model sends a page request with a PRG (Page Request Group) index, receives a group response, then uses ATS to request translation. PRI (page-request service) has its own per-request allocation, not one credit per group. Requests and group responses use TC0, with no general completion-order guarantee.
