Lane Margining examines receiver timing and voltage margin. Start from its Extended Capability (configuration-space extension), then establish port, lane numbering, and readiness before accessing controls and results. Flit logging and error injection serve separate diagnostic purposes.

Walk from the capability to Lane 3

Author scenario: let C be a valid capability base and assume the maximum width includes Lane 3. Read Figure 7-125 for layout, Figure 7-126/Table 7-111 for ID, Figure 7-128/Table 7-113 for readiness, then Figure 7-129/Table 7-114 for controls. Four bytes per lane put Lane 3 Control at C+14h and Status at C+16h. Entries beyond Maximum Link Width are undefined. Command semantics continue in 4.2.18 and 8.4.4; a control write alone is not a completed measurement.

Choose the diagnostic mechanism

Use 7.7.7/Figure 7-97 for 64.0 GT/s PHY information, 7.7.8/Figure 7-103 for Flit logging, and 7.7.9/Figure 7-120 for Device 3. Device Status 3 distinguishes Initial Link Width from current Negotiated Link Width. Flit Error Injection (intentional test-error generation), 7.8.13/Figure 7-211, is optional and Flit-only. Discovery does not imply that routine observation should enable injection.

Keep results tied to their context

Record port, default lane number, receiver, active rate/mode, command, and status. Preserve retraining or speed-change times. Section 7.7.7 notes that 64.0 GT/s parity errors are recorded in the 16.0 GT/s parity registers and recommends clearing those registers on speed changes when tracking a specific speed. A speed embedded in a register name is not sufficient to locate all evidence.
