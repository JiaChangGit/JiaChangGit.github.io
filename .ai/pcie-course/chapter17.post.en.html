FC (Flow Control) tracks buffer space at the adjacent receiver. Link replay handles transmission integrity, while a Completion (transaction response) belongs to the request itself. We place all three along one path so their participants and guarantees stay clear.

Calculate the right credit classes

Table 2-44 separates Posted, Non-Posted, and Completion resources into header and data classes. Table 2-45 maps packet types to those classes. A normal Memory Write uses PH/PD; a Memory Read request uses NPH, while returned read data uses CplH/CplD.

Author example: a normal Non-Flit Memory Write carrying 20 bytes needs 1 PH and ceil(20/16)=2 PD, since a data credit is 4 DW, or 16 bytes. Sufficient data credits alone do not pass the gate when the header credit is missing.

Why keep end-to-end checking?

LCRC (Link Cyclic Redundancy Check) and sequence numbers protect an individual link. Corruption inside an intermediate component may escape that link-level coverage. Section 2.7 therefore defines ECRC (End-to-End CRC), generated at the source over invariant fields and checked under the applicable support and enable conditions. ECRC (end-to-end integrity checking) differs from Data Poisoning, which marks data known to be unreliable rather than repairing it.

Change the replay model for Flit Mode

Flit Mode replays Flits and carries integrity information including LCRC, FEC (Forward Error Correction), and sequence numbers. The rules on p.300 explicitly exclude Ack/Nak DLLPs from Flit replay. Flow control still accounts for transaction resources, with possible shared and dedicated pools. Select the negotiated mode and features before applying the diagram.

Locate the waiting interval

Freed space takes time to become an UpdateFC, cross the link, and reach the sender. Informational Appendix H explains update-latency calculations using payload limit, overhead, and width. It does not mandate a particular internal algorithm. Diagnose a stall by identifying the missing credit class and update progress; distinguish that from replay waiting.
