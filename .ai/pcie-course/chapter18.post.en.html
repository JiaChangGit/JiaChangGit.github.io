A TLP (Transaction Layer Packet) is packed into Flits (fixed-size transfer units), then encoded for the active lane rate. These are distinct layers: one Flit is not one transaction, and its capacity is not all application data.

Separate negotiated mode from line encoding

The identification note on p.309 distinguishes Supported, Disable, negotiated Enabled, and Status. Capability alone does not establish the negotiated mode. At 2.5/5.0 GT/s the link uses 8b/10b; at 8.0/16.0/32.0 GT/s it uses 128b/130b; at 64.0 GT/s it uses 1b/1b with PAM4 and Flit Mode. Lower rates can also carry Flits under their corresponding encoding rules.

Locate a byte before following its lane

Start with the 256-byte allocation in section 4.2.3.3, then use the width-specific placement in Tables 4-10 through 4-14. DLP (Data Link Layer Payload) occupies bytes 236–241, CRC occupies 242–249, and correction bytes occupy 250–255. The author ratio 236/256=92.1875% describes the TLP region only, before transaction headers, padding, control traffic, and stalls.

Connect correction, detection, and replay

PAM4 (four-level pulse-amplitude modulation) carries two bits per signaling interval but has smaller voltage separation and greater sensitivity to noise and bursts. FEC (Forward Error Correction) provides limited correction; Flit CRC and replay provide additional protection. Appendix J identifies the alpha-power and encoder/decoder material; J.2 shows the data/check/parity relation for 84-to-86-byte encoding. Appendix K identifies the CRC matrix material. These help verify outputs without mandating the same internal hardware structure.

Choose the right appendix

Table B-1 maps data bytes and Running Disparity (the lane coding imbalance state) to 8b/10b symbols. Appendix C gives scrambling examples; C.1 explicitly permits other implementations producing the same output. Choose between symbol coding, scrambling, and Flit placement before opening an appendix.
