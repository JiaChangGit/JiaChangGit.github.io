版本與來源怎麼讀？

目前已完成章節的欄位與圖表以 PCI Express Base Specification Revision 6.0 為準，韌體背景另參考 PCI Firmware Specification Revision 3.3。Firmware 3.3 列出的 Base 參考版本為 5.0，因此教材逐項保留來源版本，不把兩份文件當成同版配套。

章內引用會列出章節、適用的 Figure／Table 與頁碼。補充資料標明來源及版本；作者設計的配置、讀值與推演也會另行標示。後續進階章節若需要其他規格，會在完成查證後再納入教材。
