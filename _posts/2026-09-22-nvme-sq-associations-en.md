<section id="topic-overview" class="topic-overview">
<p class="reader-paragraph opening"><span class="paragraph-number" aria-label="00.01">00.01.</span><span class="paragraph-text">A host knows which namespace an I/O targets, but the controller can also benefit from knowing which storage set a submission queue is intended to serve. SQ Associations supplies that hint when the queue is created. This report connects storage membership, queue setup and command routing, explaining when the hint helps and why successful I/O alone does not prove correct routing.</span></p><dl class="term-note" aria-label="Terms in this passage"><div><dt>SQ Associations</dt><dd>A queue-creation hint identifying the NVM Set that an SQ is intended to serve.</dd></div><div><dt>controller</dt><dd>Controller, the entity that implements the NVMe interface, fetches commands, and reports completions.</dd></div><div><dt>namespace</dt><dd>A logical storage space selected by NSID.</dd></div><div><dt>Host</dt><dd>The system running the operating system and issuing NVMe commands.</dd></div><div><dt>I/O</dt><dd>Input/Output, the class of data operations performed on a namespace.</dd></div><div><dt>SQ</dt><dd>Submission Queue; a memory queue in which the host places commands for execution.</dd></div></dl>
<h2 id="main-ideas">The main ideas</h2>
<div class="topic-map">
<article><span class="axis-number">01</span><h3>Distinguish three relationships</h3><p class="axis-paragraph"><span class="axis-paragraph-number" aria-label="01-01">01-01</span><span class="paragraph-text">A namespace belongs to a set, an SQ is associated with a set, and completions go to a CQ. Each relationship answers a different question; identifiers are not interchangeable.</span></p><dl class="term-note" aria-label="Terms in this passage"><div><dt>CQ</dt><dd>Completion Queue; a memory queue in which the controller posts command completions.</dd></div></dl></article>
<article><span class="axis-number">02</span><h3>Check the hint’s prerequisites</h3><p class="axis-paragraph"><span class="axis-paragraph-number" aria-label="02-01">02-01</span><span class="paragraph-text">Discover controller support, distinguish mode enablement from support, and consider the set’s current operating window. Capability bits alone provide no fixed application-latency bound.</span></p></article>
<article><span class="axis-number">03</span><h3>Connect storage queries to queue creation</h3><p class="axis-paragraph"><span class="axis-paragraph-number" aria-label="03-01">03-01</span><span class="paragraph-text">Read actual set identifiers and namespace membership, then encode Create I/O SQ. List index, byte position and identifier serve different purposes, as does the count encoding for a 64-entry queue.</span></p><dl class="term-note" aria-label="Terms in this passage"><div><dt>entry</dt><dd>One list record; an NVM Set Attributes Entry occupies 128 bytes.</dd></div><div><dt>index</dt><dd>A zero-based entry position within the list.</dd></div></dl></article>
<article><span class="axis-number">04</span><h3>Check routing for each I/O</h3><p class="axis-paragraph"><span class="axis-paragraph-number" aria-label="04-01">04-01</span><span class="paragraph-text">Follow command NSID to set to an associated SQ. Compare invalid creation parameters with later queue misuse and their different specified consequences.</span></p><dl class="term-note" aria-label="Terms in this passage"><div><dt>NSID</dt><dd>Namespace Identifier; identifies the namespace targeted by an I/O command.</dd></div></dl></article>
</div>
<p class="reader-paragraph"><span class="paragraph-number" aria-label="00.02">00.02.</span><span class="paragraph-text">Assumes operating systems, computer organization and basic SSD knowledge. Sets 7/9, SQ3/4/5, CQ2 and namespace identifiers are illustrative; actual support and identifiers come from the device.</span></p>
<p class="reader-paragraph"><span class="paragraph-number" aria-label="00.03">00.03.</span><span class="paragraph-text">Start with the queue selection for one I/O, establish the overview, then follow queries, fields and results.</span></p>
<div class="overview-connections"><h3>Connecting the main ideas</h3>
<p class="reader-paragraph"><span class="paragraph-number" aria-label="00.04">00.04.</span><span class="paragraph-text">One example runs throughout: namespaces A/B belong to set 7 and C to set 9. SQ3/SQ4 serve set 7, SQ5 serves set 9, and completions can share CQ2. Follow where each identifier comes from, where it is encoded and how it selects an SQ.</span></p>
<p class="reader-paragraph"><span class="paragraph-number" aria-label="00.05">00.05.</span><span class="paragraph-text">SQ Associations is an optional hint for Predictable Latency Mode. Support for the hint, correctness of the hint and the mode’s current quality of service are separate questions.</span></p><dl class="term-note" aria-label="Terms in this passage"><div><dt>Predictable Latency Mode</dt><dd>A mode providing deterministic read/write latency per NVM Set during operating windows subject to specified conditions.</dd></div></dl>
</div>

<dl class="term-note" aria-label="Terms in this passage"><div><dt>CTRATT</dt><dd>Controller Attributes; a field of capability bits in Identify Controller.</dd></div><div><dt>DTWIN</dt><dd>Deterministic Window; the operating window in which a set can provide deterministic read/write latency.</dd></div><div><dt>PCIe</dt><dd>PCI Express, the transport and device interconnect used by an NVMe memory-based controller.</dd></div><div><dt>PLM</dt><dd>Predictable Latency Mode; the CTRATT bit reporting mode support.</dd></div><div><dt>SQA</dt><dd>SQ Associations; the CTRATT bit reporting support for queue-to-set association.</dd></div></dl>
<!-- claim:SQA-SUPPORT -->
<p class="reader-paragraph"><span class="paragraph-number" aria-label="02.01">02.01.</span><span class="paragraph-text">A controller supporting SQ Associations must advertise SQA, NVM Sets and Predictable Latency Mode in CTRATT. These support bits do not mean that every set has the mode enabled or is currently in a deterministic window.</span></p><details class="source-note"><summary>Sources: Base 2.4 §8.1.28</summary><p>Source: NVME-BASE-2.4, Rev. 2.4, §8.1.28, printed pages 732-733, PDF pages 758-759</p></details>
<aside class="worked-example"><h3>Illustrative example</h3><p class="reader-paragraph"><span class="paragraph-number" aria-label="02.02">02.02.</span><span class="paragraph-text">The three relevant bits are SQA bit 8, PLM bit 5 and NSETS bit 2, giving mask 0124h. Test (CTRATT &amp; 0124h)==0124h rather than requiring the entire field to equal 0124h, since other capabilities may also be present.</span></p><dl class="term-note" aria-label="Terms in this passage"><div><dt>NSETS</dt><dd>NVM Sets; the CTRATT support bit for NVM sets.</dd></div></dl></aside>

<!-- claim:SQA-INVENTORY -->
<p class="reader-paragraph"><span class="paragraph-number" aria-label="03.01">03.01.</span><span class="paragraph-text">The host needs two kinds of information: the NVM Set List identifies accessible sets, while Identify Namespace identifies the set containing a namespace. List position, NVM Set Identifier and NSID are different values.</span></p><details class="source-note"><summary>Sources: Base 2.4 §5.2.14.2.4</summary><p>Source: NVME-BASE-2.4, Rev. 2.4, §5.2.14.2.4, printed pages 388-389, PDF pages 414-415</p></details>

Namespace queries map NSIDs 11/12 to set 7 and NSID 21 to set 9. Store those actual mappings, not list indices 0/1 as set identifiers.</span></p></aside>

<details class="review-question" id="qa-sqa-route"><summary>3. NSID21 belongs to set 9, and SQ3/SQ5 share CQ2. Can either SQ be selected?</summary>
<div data-qa-answer="sqa-route"><p class="reader-paragraph review-answer"><span class="paragraph-number" aria-label="07.03">07.03.</span><span class="paragraph-text">Use SQ5, associated with set 9 in this example.
